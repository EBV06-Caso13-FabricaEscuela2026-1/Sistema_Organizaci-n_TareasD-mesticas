Sistema de Organización de Tareas Domésticas orientado a hogares compartidos, diseñado para facilitar la asignación, seguimiento y cumplimiento de responsabilidades entre los miembros del hogar.

La aplicación permite gestionar usuarios y grupos familiares, asignar tareas con fechas límite y niveles de prioridad, monitorear el estado de cada actividad y llevar un historial de cumplimiento por usuario. Además, incluye reportes que permiten analizar la distribución de responsabilidades, promoviendo una convivencia más organizada y colaborativa.
